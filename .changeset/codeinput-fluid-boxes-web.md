CodeInput: the boxes are fluid, as the sign-in design draws them, so an 8-digit code fits a sign-in card and a phone. They share the row's width (aspect 1 : 1.18, 28–60px wide; at ≤ 540px no upper cap, a 6px gap and 20px digits) instead of a fixed 44×52. This changes the layout of every existing CodeInput: the row is now full width with the boxes spread across it, not a centred group of fixed boxes.
